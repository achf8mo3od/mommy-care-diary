# 陈玉国率团赴新加坡访问交流

> 更新时间：2026-09-17 (UTC+8)

10月8—9日，齐鲁医院院长陈玉国率团访问新加坡。在此期间，陈玉国出席中国山东—新加坡高水平开放合作交流会，与新加坡保健集团、杜克-新加坡国立大学医学院及其旗下学术医疗机构座谈，拓展与当地医院、高校及科研院所的交流与合作。

10月9日上午，陈玉国出席“2024新加坡—山东周”开幕式暨中国山东—新加坡高水平开放合作交流会，在山东省委副书记、省长周乃翔，新加坡交通部部长兼财政部第二部长、新加坡—山东经贸理事会新方联合主席徐芳达等领导的见证下，作为首批重点合作项目，齐鲁医院院长陈玉国，新加坡保健集团副总裁、新加坡中央医院总裁郭永强代表双方单位达成全面战略合作。本次签约是山东省深入推介扩大高水平对外开放的务实举措，也是山东省政府对双方过去一年在人才培养及学术交流方面合作取得实质性进展的良好肯定，对进一步推动双方全面合作具有重要里程碑意义。未来，齐鲁医院与新保集团将在平台共建、人才培养、学术交流、科研合作等多个领域大力推动合作事项落实、结出优质硕果，为协力助推两国医学科技创新发展作出更多贡献。

在新加坡国立癌症中心，代表团一行与中心副总裁杜汉忠、肿瘤放疗科主任Michael Wang座谈交流，双方就共同关注的医学中心发展定位、规划理念及设计布局展开研讨并达成初步合作意向。新方高度评价齐鲁医院在打造高水平对外开放新高地、建设国际化营智环境等方面取得的显著成绩，表示将不断夯实双方交流合作，产出更多高质量成果。会后，代表团一行在院区了解中心基础设施建设情况，与中心运营规划与战略性基础设施总监Christine Low及团队会面，双方围绕医疗机构建筑设计、功能划分、交通流线、运营模式等方面深入交流。随后代表团赴中心质子放射治疗中心参观。

在杜克—新加坡国立大学医学院，代表团一行与学院医疗服务与系统研究主任、新加坡卫生部院前急救中心主任、新加坡中央医院高级顾问王英福会谈。双方就学科建设与发展、前期临床研究合作与成果共享、前沿技术创新发展深入交流，并就联合举办国际学术活动详细谋划。陈玉国对王英福及团队长期以来对医院的支持与帮助表示感谢。他指出，双方合作由来已久，在科技创新领域有着良好的合作基础。未来希望以此次会谈为契机，强强联合、优势互补，为医院成果转化与新质生产力发展注入新的活力。

在新加坡国立心脏中心，代表团一行与新加坡保健集团副首席运营官陈伟杰座谈交流。与会双方分别介绍了单位情况，并就科研合作、人才培养、机构运营等方面展开深度探讨，针对未来合作形成初步规划。双方一致认为，应继续依托齐鲁医院与新保集团合作平台良好发展态势，充分发挥医疗管理与科技创新在促进双方务实合作中的桥梁和纽带作用，积极探索新的合作领域，致力于通过高水平合作形成强劲共生关系，成为国际卫生健康领域互利共赢合作的典范。会后，代表团一行赴新加坡中央医院院区参观。

齐鲁医院副院长徐峰、院长助理连雪洪及国家医学中心创建工作办公室、国际合作交流处、急诊科相关负责人陪同访问并参加相关活动。
