# 生娃前、生娃后判若两人,看完这些照片,看谁还说得出生孩子轻松

很多女性在结婚后都会被催生子，虽然“结婚生子”是大部分人的必经之路，可结婚容易，生子未必轻松。

生娃前、生娃后判若两人

之前看过一组照片，照片里的人一个年轻漂亮，一个像是被生活磋磨好久，仔细对比才发现，这明明就是同一个人，在去了解，**原来是生娃前和生娃后的对比图。**

很多宝妈看完之后不得不感叹，这不就是自己的模样，生娃前还自诩“年轻有活力”，生娃后明显“老了好几岁”。

生娃前自己简单收拾一下，就非常有精气神，可自从生完宝宝之后，哪怕自己打扮的多么用心，**身上总是带着“妈妈的味道”。**

这些变化不仅仅体现在身材走样，皮肤粗糙，主要还是**由内而外的一种疲惫感**，而这种疲惫感没有经历过的人，真的是无法理解。

看完这些照片，看谁还说得出生孩子轻松！那么为什么生娃前和生娃后会有如此大的变化呢？这其中主要是什么原因导致的呢？

为什么生娃前后会有巨大差别？

**① 生娃后身体发生变化**

大部分宝妈在生完宝宝之后，身体都会发生不同程度的变化，有的只是身材发生变化，但有些宝妈身体却出现不同程度的问题，比如脱发、漏尿等等。

这些问题已经不再是个人形象问题，还**影响着宝妈们的健康**，宝妈们一定不要忽视，发现问题及时解决，不要熬。

**② 生娃后精神状态不好**

宝妈生完宝宝之后，身体本来虚弱，需要好好休息和养护，可是很多家庭却将带娃的重担全权交给宝妈。

小娃娃不仅难哄，吃喝拉撒每一样都少不得细心照顾，**身体虚弱的宝妈们根本无法好好休息，**精神状态肯定会雪上加霜，整个人看起来没有精神在所难免。

**③ 生娃后心态发生巨大变化**

生娃前，宝妈只需要照顾好自己就可以，生活重心也会围绕着自己，可自从生娃以后，生**活重心就会全在宝宝身上。**

这时的宝妈已经没有什么精力关注自己，什么个人形象，什么穿衣打扮，就连身体健康都容易被忽略。当宝妈心态发生了变化，整个人的气场也会发生变化。

宝妈应该做出什么样的改变？

**① 学会放手**

照顾宝宝不是一朝一夕的事情，**宝妈们不要总是大包大揽，**什么事情都往自己身上压。我们应该学会放手，有些事情真的可以交给宝爸来做，都是第一次当父母，不会的都可以去学习，不要让自己太过疲惫。

**② 拒绝摆烂**

有些宝妈情绪状态都非常不好，感觉自己改变不了什么，就开始学会摆烂，身材走样放任不管，皮肤不好放任不管……这种自我放弃的行为，真的不可取。**未来的路还有很长**，我们要相信只要我们努力去改变，任何事情都会有好转的。

**③ 做回自己**

有了宝宝之后，很多宝妈会将心思都放在宝宝身上，自己的事业、自己的喜好都放弃了，完全是丧失自我的状态，长时间如此整个人就会变得低迷。

宝妈们要清楚，并不是生完宝宝我们就不是自己了，**我们要学会爱自己，**宝宝需要我们照顾，我们自己也要善待自己，做回自己，不要迷失自我。
